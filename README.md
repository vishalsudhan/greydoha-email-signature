# Grey Doha Email Signature: Crahan Pinto

Static site hosting the email signature and its images.

- `index.html`: preview with **Copy for Gmail** / **Copy for Outlook** buttons and install steps
- `signature.html`: Outlook version (sharp 2x images; save as `.htm` for classic Outlook)
- `signature-gmail.html`: Gmail version (normal-size images)
- `assets/`: animated logo (1x and 2x) and icons

Live: https://greydoha-email-signature.vercel.app
